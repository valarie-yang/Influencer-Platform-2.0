# Demo script

1. Start with a fictional creator persona.
2. Show the structured analysis: audience, positioning, pillars, tone, and constraints.
3. Select four synthetic monthly topics and assign target weeks.
4. Turn one topic into an editable 60–90 second script.
5. Show the shot list, B-roll, subtitle focus, and editing rhythm.
6. Move the work into the publishing board and complete one task.
7. Point out that every step remains editable and that publishing is not automatic.
8. End on the Mock AI boundary, structured-output example, and future provider-integration plan.

The current public repository contains the documentation package. The walkthrough should use a separately reviewed runnable build or recorded demo when available; do not imply that this documentation-only commit is the runnable source itself.
